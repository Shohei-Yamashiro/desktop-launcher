Hashelf
================================

よく使うファイル・フォルダー・URL を登録して、キー操作ひとつで呼び出して開くランチャーです。
グループで階層に分けたり、タグを付けて名前やタグで探したりできます。

ご利用の前に、利用条件（LICENSE.txt）をお読みください。
画像付きの説明は、同じフォルダの「ハッシェルフ（Hashelf）のご紹介.pdf」にあります。

このアプリは、作者が AI コーディングエージェント（Cursor）と協働して開発しました。
要件と設計の判断、動作の確認は作者が行い、コードの作成は主に AI エージェントが担当しています。

■ 動作環境
  Windows 10 / 11（64 ビット版）
  インストールは不要です。動かすために別のソフトを入れる必要はありません。

■ 起動
  1. ダウンロードした zip ファイルを右クリックし、「すべて展開」を選んで展開します。
     （zip のまま中の Hashelf.exe を開くと、正しく動きません）
  2. 展開したフォルダの Hashelf.exe をダブルクリックします。
  3. ランチャーの画面が開きます。
     画面の右下の通知領域（タスクトレイ）にもアイコンが出ます。

  初めて起動するとき、「Windows によって PC が保護されました」という警告が出ることがあります。
  「詳細情報」を押し、表示された「実行」を押してください。
  本ソフトウェアには発行元を証明する電子署名を付けていないため、この警告が出ます。
  展開する前に zip ファイルを右クリック →「プロパティ」→「許可する」にチェック →「OK」とすると、
  この警告が出なくなる場合があります。

■ 使い方
  ・呼び出す
      Ctrl + Alt + Space を押すと、ランチャーが開きます（もう一度押すと小さくなります）。
      呼び出すキーは、右上の歯車のボタン（設定）の「呼び出すキー」で変えられます。
      Esc を押すか、ほかのウィンドウをクリックすると、小さいアイコンになって画面に残ります。
      小さいアイコンはクリックで開き、ドラッグで好きな場所に動かせます。
  ・登録する
      エクスプローラーやデスクトップから、ファイル・フォルダー・URL を画面にドラッグします。
      画面上部の「＋ファイル」「＋フォルダー」でも選べます。
      ドラッグで追加するときは、右上のピンのボタン（固定）をオンにすると、画面が小さくならずに済みます。
      URL は「＋URL」を押し、URL と名前を入力しても登録できます（http:// や https:// は省略できます）。
      エクスプローラーでコピーしたファイル・フォルダーや、コピーした URL は、一覧で Ctrl+V を押すと登録できます。
      （コピーした文字は、http:// か https:// で始まるときだけ URL として扱います。
        「＋URL」を押したときも、コピーしてある URL がこの形のときだけ、URL の欄に入ります）
      登録した URL は、ふだん使っているブラウザで開きます。
      登録済みのファイル・フォルダーを追加しようとすると、登録済みの項目が選ばれた状態になります。
      URL は、同じものを何度でも登録できます。
  ・開く
      項目をダブルクリックするか、選んで Enter を押します。
  ・整理する
      「＋グループ」でグループを作り、項目をドラッグして中に入れます。
      項目を右クリックすると、「編集…」「お気に入りに追加」「移動」「上へ」「下へ」「ランチャーから削除」などが選べます。
      「編集…」（F2）では、名前とタグに加えて、ファイル・フォルダーの場所や URL も変更できます。
      複数の項目を選んでいるときは、「タグを編集…」でタグだけをまとめて変更できます。
      「編集…」の「アイコン」の「画像を選ぶ…」で、好きな画像（PNG・ICO・JPG など）をアイコンにできます（グループにも設定できます）。
      画像は data\icons にコピーして使うので、元の画像を消しても表示は残ります。「元に戻す」で既定のアイコンに戻ります。
      Web ページの項目は、既定ではサイト名の頭文字を色付きの丸で表示します（同じサイトは同じ色）。
      Ctrl や Shift を押しながらクリックすると、複数の項目をまとめて操作できます。
      画面上部の右にある「開く」「閉じる」のボタンで、すべてのグループをまとめて開く／閉じることができます。
      グループを右クリックして「中のグループもすべて開く」「中のグループもすべて閉じる」を選ぶと、
      そのグループの中だけをまとめて開く／閉じることができます。
  ・探す
      上の検索欄に名前を入力すると、一致する項目だけが表示されます。
      「#」に続けてタグ名を入力すると、タグで絞り込めます（候補が出るので、↑↓ で選んで Tab か Enter）。
      グループに付けたタグは、中の項目にも引き継がれます。
      検索欄で Enter を押すと先頭の結果が選ばれ、もう一度 Enter を押すと開きます。
  ・お気に入り
      行の先頭の薄い ☆ をクリックすると、お気に入りになり ★ に変わります。
      右クリックの「お気に入りに追加」、項目を選んで Ctrl + D、「編集…」画面の「お気に入り」でも切り替えられます。
      画面上部の「お気に入り」タブで、お気に入りの項目だけを一覧にできます（「すべて」タブで元の一覧に戻ります）。
      Ctrl + Tab でもタブを切り替えられます。
  ・よく使う
      「よく使う」タブには、よく開く項目が、開いた回数と新しさの順に最大 20 件並びます。
      長く開いていない項目は、回数が多くても順位が下がります。
      項目を右クリックして「よく使うから外す」を選ぶと、その項目の記録を消して一覧から外せます。

  ショートカット（.lnk / .url）について：
    初期設定では、ショートカットのファイルを登録すると、そのコピーをアプリのフォルダー（data\links）に
    保存し、元のショートカットはごみ箱に移します（デスクトップを片付けるための機能です）。
    元のショートカットを残したいときは、右上の歯車のボタン（設定）を押し、
    「ショートカット（.lnk / .url）を登録したら、元のファイルをごみ箱に移す」のチェックを外してください。
    ショートカット以外のファイルやフォルダーは、移動もコピーもしません。

■ 終了
  画面の右下の通知領域のアイコン、または小さいアイコンを右クリックし、「終了」を選びます。
  （ランチャーの画面を閉じても、アプリは終了せず小さいアイコンになります）

■ ブラウザのブックマークの取り込み
  右上の歯車のボタン（設定）の「ブラウザのブックマーク」の「取り込む…」を押すか、
  一覧の空いている所を右クリックして「ブラウザのブックマークを取り込む…」を選びます。
  1. 「取り込み元」で、Edge・Chrome などのプロファイルを選びます（Edge では「お気に入り」と呼ばれているものです）。
     ほかのブラウザは、ブックマークを HTML ファイルに書き出してから、「HTML ファイルから…」で選びます。
  2. 取り込むフォルダーにチェックを付けて、「取り込む」を押します。
  取り込んだ項目は、新しいグループ 1 つにまとめて入ります。要らなくなったら、そのグループを削除すれば元に戻せます。
  「お気に入りバー（ブックマークバー）の項目をお気に入りにする」を選ぶと、そこにある項目に ★ が付きます。
  ブラウザのファイルは読むだけで、書き換えません。

■ Windows 起動時に開始
  通知領域のアイコンを右クリックして「Windows 起動時に開始」を選ぶか、設定でチェックを付けると、
  Windows にサインインしたときに自動で起動します（小さいアイコンだけが出ます）。
  この設定をオンにしたときだけ、レジストリ（HKEY_CURRENT_USER の Run キー）に登録します。

■ データ
  登録した項目と設定は、展開したフォルダの中の data フォルダに保存します。
    data\items.json     登録した項目・グループ・タグ・お気に入り、開いた回数と最後に開いた日時
    data\settings.json  設定、小さいアイコンの位置、タグの色
    data\links\         取り込んだショートカットのコピー
    data\icons\         アイコンに設定した画像のコピー
  バックアップするときは、アプリを終了してから data フォルダをコピーしてください。
  初期状態に戻すときは、アプリを終了してから data フォルダを削除してください。
  外部との通信は一切行いません。

■ 削除（アンインストール）
  1. 「Windows 起動時に開始」をオンにしている場合は、先にオフにします。
  2. アプリを終了してから、展開したフォルダごと削除してください。
  本ソフトウェアは、展開したフォルダの外にファイルを作りません。
  レジストリに書き込むのは「Windows 起動時に開始」をオンにしたときだけです。
  オフにせずにフォルダを削除した場合は、タスク マネージャーの「スタートアップ アプリ」に
  「Hashelf」が残ります。そのままでも害はありませんが、右クリックして「無効化」を選べば止められます。

■ うまく動かないとき
  ・呼び出すキー（初期設定は Ctrl + Alt + Space）で開かない
      ほかのアプリが同じキーを使っていると、起動時に「登録できませんでした」と通知が出ます。
      通知領域のアイコンか、小さいアイコンをクリックして開き、
      設定の「呼び出すキー」で別の組み合わせを選んでください。
  ・ドラッグしようとすると画面が小さくなってしまう
      右上のピンのボタン（固定）をオンにしてから、ドラッグしてください。
  ・「見つかりません。移動または削除された可能性があります。」と出る
      登録したファイルやフォルダーが移動または削除されています。
      項目を右クリックして「ランチャーから削除」し、登録し直してください。
  ・フォルダを別の場所に移したら、Windows 起動時に開始しなくなった
      設定の「Windows 起動時に開始」を、一度オフにしてからオンにし直してください。
  ・「保存データを読み込めませんでした」と出る
      壊れたファイルは data フォルダに items.broken-（日時）.json という名前で残しています。
      バックアップがあれば、アプリを終了してから data フォルダを戻してください。
